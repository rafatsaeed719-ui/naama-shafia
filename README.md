# النعمة الشافية — Healing Grace

برنامج خدمة النعمة الشافية: قطاعات (تعليم، صحة، احتياجات، كنائس، اجتماعية)، ملف كامل لكل مخدوم، زيارات ومهام وطلبات، كشوف حساب، تنظيمات وإشعارات.

- `www/` البرنامج (HTML/JS) — `www/config.js` فيه إعدادات Firebase و Cloudinary
- `firestore.rules` قواعد الأمان (تتلصق في Firebase > Firestore > Rules)
- كل push على `main` بيعمل APK في Releases
